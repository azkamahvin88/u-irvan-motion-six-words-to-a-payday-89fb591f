A six-word story about an AI agent's first payday: "Paycheck cleared. So did my memory." The paycheck clears the bank — and the agent's memory clears too. A judge model compares entries pairwise and picks the one that fits the most story, surprise and feeling into exactly six words.

## Run it

```sh
python3 main.py
```

Writes the story to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Deterministic: the same fixed string on every run, no randomness, no clock, no network.
